# 🧭 LifeOS · 日常规划与知识复盘

一个**完全本地运行**的个人生活管理桌面应用，帮你安排每一天、养成好习惯、沉淀知识，并用**费曼学习法 + DeepSeek AI** 把学过的东西真正变成自己的。界面采用**橙白高级感**设计：暖白底、克制橙、精细排版、柔和光影。

> 数据全部保存在本地 `data/lifeos.db`（SQLite），不上传任何服务器，你的笔记和复盘内容永远属于你自己。

## 🧠 费曼复盘怎么用（核心流程）

1. **投喂**：在「费曼复盘」点「新建复盘」，把你正在学的内容（课程笔记、书本段落、单词表…）粘贴进去，创建卡片；
2. **拆解**：点「用 AI 生成讲解任务」，AI 会给出核心要点、讲解任务（用大白话讲给小学生听）、易错点；
3. **讲解**：不看原文，在输入框里用自己的话把内容讲一遍，写下来；
4. **点评**：AI 从 **准确性 / 完整性 / 清晰度 / 简洁性** 四个维度打分，指出错误、遗漏和改进建议；
5. **复习**：通过的卡片按遗忘曲线自动安排复习（1→3→7→15→30→60 天），每天到期的卡片会出现在「今日到期」；没通过的卡片改好后再提交，直到讲明白为止。

## 🚀 快速开始

### 环境要求
- Windows 10/11
- Python 3.10+（已安装并加入 PATH）

### 启动
**双击 `启动LifeOS.cmd`** —— 首次运行会自动创建虚拟环境并安装依赖，之后每次双击即可打开应用窗口。

如果桌面窗口打不开（例如缺少 WebView2 运行时），可用 `启动LifeOS-浏览器模式.cmd`，会在默认浏览器中打开。

### 首次设置
1. 打开应用后进入「⚙️ 设置」；
2. 填入你的 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 申请，费用很低）；
3. 点「🔌 测试连接」确认可用，点「保存设置」；
4. （可选）填写个人档案，让 AI 的点评更贴合你的背景。

> 不填 API Key 也能用任务/习惯/笔记功能，只有费曼点评和 AI 总结需要联网调用。

## 🏗️ 技术说明

```
LifeOS/
├── main.py                  # 入口：pywebview 桌面窗口 + 本地服务
├── requirements.txt         # 依赖
├── backend/
│   ├── database.py          # SQLite 连接/建表/迁移/事务助手
│   ├── server.py            # FastAPI 装配（OpenAPI、安全边界、异常处理）
│   ├── routes/              # 薄适配层：参数 → 调服务 → 响应
│   └── services/
│       ├── ai.py            # DeepSeek API 客户端（OpenAI 兼容）
│       ├── feynman.py       # 费曼提示词与结果解析
│       ├── course_parser.py # 课表解析器（教务系统/经典格式）
│       ├── semester.py      # 学期周次计算（纯函数）
│       └── srs.py           # 费曼复习排程（纯函数）
├── frontend/                # 本地 Web UI（原生 JS，无外部依赖）
│   ├── index.html
│   ├── css/style.css
│   └── js/
└── data/lifeos.db           # 你的数据（首次运行自动创建）
```

- **后端**：FastAPI + Uvicorn，监听 `127.0.0.1` 随机端口；**OpenAPI 文档**（`/docs`）默认开启，为未来移动端客户端对接提供 API 契约
- **安全边界**：Host 头校验（防 DNS rebinding）+ 启动时随机**会话 Token**（注入 URL，`/api/*` 需带 `X-LifeOS-Token`）
- **数据层**：SQLite（WAL + busy_timeout）、**schema 迁移机制**、多步写事务助手、关键索引
- **业务逻辑**：周次计算（semester）、复习排程（srs）为纯函数，可独立测试、可被移动端复用
- **前端**：原生 HTML/CSS/JS，离线可用（含自研轻量 Markdown 渲染器）
- **桌面壳**：pywebview（Edge WebView2），打不开时自动回退到浏览器
- **数据**：SQLite 单文件 + `data/images`（图片）；备份 JSON 已含全部表（课程/反思等），导出时 API Key 自动脱敏

## 📦 打包成 exe（可选）

## 🛠️ 常见问题

**双击启动脚本后窗口闪一下就没了？**
- 首次运行会自动创建虚拟环境并安装依赖（1~3 分钟），期间只有黑窗口是正常的，请等待；
- 如果仍打不开，请查看 `data/lifeos.log`，里面记录了每一步启动信息，把最后几行发给我即可定位。

**桌面窗口打不开，怎么办？**
- 自动会回退到浏览器打开，也可以直接双击 `启动LifeOS-浏览器模式.cmd`；
- 若回退也没反应，多半是缺少 [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)，安装后重启即可。

**费曼点评报「尚未配置 DeepSeek API Key」？**
- 到「⚙️ 设置」页填写 API Key 并点「测试连接」，保存后再用。
